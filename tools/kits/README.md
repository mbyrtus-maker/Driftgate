# Model kits
The CC0 kits the model-pack builders read (tools/build_models.py, tools/station.py). The game does not load these:
the built models are packed into index.html. Only needed to rebuild or add models.
- kenney-space-kit/GLTF: Kenney Space Kit (kenney.nl), CC0: work ships, stations, depots, outposts, works, capital parts.
- quaternius-lowpoly-spaceships/OBJ: Quaternius Lowpoly Spaceships (Jan 2018), CC0: fighter and scout hulls.
